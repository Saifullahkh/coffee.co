# ☕ Coffee.co — Hotel & Coffee Lounge Footer Component

A premium, modern, and high-performance **Footer Component** engineered for luxury hotels, cafes, and hospitality platforms. Built with React and Bootstrap 5 for seamless responsiveness across all screen sizes.

---

## ✨ Features

- **📱 Fully Responsive:** Auto-adjusting grid layout optimized for Mobile, Tablet, and Desktop viewports.
- **🎨 Modern Dark UI:** Styled with high-contrast typography, sleek opacity borders, and custom hover states.
- **⚡ Instant Navigation:** Clean quick-links section for frictionless user routing.
- **✉️ Integrated Newsletter:** Functional subscription input group with action trigger setup.
- **🎯 Contextual Micro-Icons:** Enhanced UX with Feather (`fi`) & FontAwesome (`fa`) icon packs.
